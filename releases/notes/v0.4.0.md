# bash-arena v0.4.0 — 536 niveles: profunda en grep y awk

El catálogo alcanza **536 niveles en 18 tracks**, con los dos tracks de
especialización al doble de tamaño: **grep y awk, 68 niveles cada uno**, para
llegar a la fluidez real con las dos herramientas más usadas del shell.

## Qué añade esta release

- **Grep a 68 niveles (+18)**: técnicas de auditoría completas —
  `-c` por fichero con ranking (`sort -t: -k2 -nr`), `-w` palabra completa,
  `-x` línea exacta + vecina con `-A`, contexto con `-B`/`-C` y **corte
  asimétrico** `-B 3 -A 1`, `-i`, stream limpio con `-h`, barrido recursivo
  filtrado `-r --include '*.log'`, **lista de patrones** `-f`, modo literal
  `-F`, localización + regreso `-l` → `cat`, extracción `-oE` de dominios e
  IPs (combina con `sort | uniq -c` para la IP dominante), clase POSIX
  `[[:digit:]]{3,}` con cuantificador, `-E` con doble ancla `^…$` y **boss**:
  la cadena SOC completa `-c métrica → IP dominante → regreso a la única OK`
  con la flag. Semi-boss `-Ff` (plantilla literal desde fichero).
- **Awk a 68 niveles (+18)**: idiomas de nivel experto — `$NF`, guard por
  `NF`, `length($NF)`, `substr()` en el guard, `BEGIN{OFS}` para recomponer
  columnas, `match()+RSTART/RLENGTH` como extractor universal, registros por
  párrafo con `RS=""`, claves compuestas `t[$1 FS $2]`, `getline` para el par
  evento→consecuencia, selección por fichero con `FILENAME == ARGV[2]`,
  **extremo dinámico guardando la fila completa** (`min` con `$0` capturado),
  comparación entre columnas (`$4 > $3`), ternario etiquetador, array por
  `NR` + recorrido inverso en END (anti-tac), clasificador con `/^#/ {next}`
  + contador + último dato, producto acumulado, **best[] por categoría**
  (campeón por grupo con fila completa) y **boss**: máquina de estados
  `prev ~ / OK / && $2 == "KO"` + `getline` para la fila de evidencia.
- **Docs actualizadas (GitHub Pages)**: contadores (536 niveles), fichas
  nuevas de cheatsheet («grep: auditoría y catálogo» y «awk: estado y
  ranking») y las soluciones paso a paso de los 36 niveles nuevos
  (`walkthroughs.generated.ts` regenerado).
- **Verificación completa**: las 36 soluciones nuevas pasadas una a una en
  contenedor Docker real (`test-levels.mjs`: setup → solución → exit 0 y
  flag en stdout), lint de niveles y del repo en verde, tests unitarios
  22/22, typecheck server/client/docs y builds del cliente y docs OK.
